# MonoBrowser

This is a simple desktop browser built using Electron and TypeScript. It's a minimal project, but it includes the core features you'd expect from a browser like tabs, navigation, and keyboard shortcuts.

## What it does

- You can open multiple tabs, type URLs or search terms in the address bar, and use standard navigation (back, forward, reload).
- There is a dedicated History button in the navigation bar that opens browsing history in a separate window.
- Keyboard shortcuts are supported: `Ctrl+T` (or Cmd+T) for a new tab, `Ctrl+W` to close the current tab, and `Ctrl+R` to reload.
- It opens Google by default on startup.
- The native window menu bar is hidden to keep the UI clean, but you can reveal it by pressing `Alt`.
- It uses a custom black and white icon that gets generated automatically during the build process.
- It supports auto-updating via GitHub Releases.

## How to run it

First, install the dependencies:

```bash
npm install
```

To run the app locally for development:

```bash
npm run dev
```

To build the production files:

```bash
npm run build
```

To package the app into a Windows installer:

```bash
npm run dist
```

## Auto-updates

When running the packaged version, the app automatically checks for updates on startup and then every 6 hours. If it finds a new release on GitHub, it downloads it in the background and prompts you to restart.

For the updater to work, make sure your GitHub release includes the files generated by `npm run dist`: the `.exe`, `.blockmap`, and `latest.yml`.

## Technical details

The project uses Electron, TypeScript, and esbuild for bundling.

Security is handled by keeping the renderer process sandboxed with `contextIsolation` enabled and `nodeIntegration` disabled. The UI communicates with the main Electron process strictly through an IPC bridge defined in `preload.ts`.

## Current limitations

Since this is a minimal build, it doesn't currently have bookmarks, a downloads manager, or session restore. The development setup also doesn't support hot-reloading yet, so you'll need to restart the app to see your changes.
