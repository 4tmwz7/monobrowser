# MonoBrowser

Minimal desktop browser MVP built with Electron + TypeScript.

MonoBrowser focuses on a small but real browser core: tabs, navigation, keyboard shortcuts, and secure Electron architecture.

## ✨ Features

- Multi-tab browsing
- Address bar navigation (URL + search input)
- Active-tab navigation controls: Back / Forward / Reload
- Keyboard shortcuts:
  - `Ctrl/Cmd + T` — new tab
  - `Ctrl/Cmd + W` — close active tab
  - `Ctrl/Cmd + R` — reload active tab
- Default startup tab: `https://www.google.com`
- Native menu bar hidden by default (shows on `Alt`)
- Custom black/white generated app icon (`assets/icon.png`)
- Auto-update support via GitHub Releases (`electron-updater`)
- Secure `main` / `preload` / `renderer` split with IPC bridge

## 🏗 Tech Stack

- Electron
- TypeScript
- esbuild (renderer bundling)
- electron-builder (packaging)

## 📦 Scripts

- `npm run dev` — full build + run Electron
- `npm run build` — clean + generate icon + compile main + bundle renderer + copy HTML
- `npm run start` — run app from current build
- `npm run dist` — package app with electron-builder

## 🔄 Auto Update

Auto update is enabled for packaged builds (`app.isPackaged === true`).

- App checks for updates on startup
- Then re-checks every 6 hours
- When update is downloaded, app asks user whether to restart now

Release artifacts needed for updater on Windows:

- `monobrowser Setup <version>.exe`
- `monobrowser Setup <version>.exe.blockmap`
- `latest.yml`

These are generated by `npm run dist` and should be uploaded to the GitHub Release for that version tag.

## 🧭 Project Structure

```text
src/
	main/
		main.ts          # app lifecycle, BrowserWindow, BrowserView tabs, navigation, history persistence
		preload.ts       # secure contextBridge API (no direct Node in renderer)
	renderer/
		index.html       # browser UI shell (tabs, toolbar, address bar)
		app.ts           # renderer interactions, state and shortcut handling

scripts/
	copy-renderer-html.mjs
	generate-icon.mjs # generates black/white icon into assets/icon.png

assets/
	icon.png
```

## 🔒 Security Model

Renderer runs with restricted privileges:

- `contextIsolation: true`
- `nodeIntegration: false`
- `sandbox: true`

All browser actions are executed through typed IPC exposed in `preload.ts`.

## 🧪 Pre-publish Checklist (GitHub)

Before pushing:

1. Run `npm run build` (must pass cleanly)
2. Verify `.gitignore` excludes `node_modules/`, `dist/`, logs, and `.env`
3. Confirm no secrets/tokens in tracked files
4. Optionally run `npm audit` and review high/critical issues

## 📌 Current MVP Limitations

- No bookmarks manager
- No downloads manager
- No session restore
- No hot-reload dev loop (current `dev` script is build-then-run)

## 🛠 Troubleshooting

- If icon/menu/UI changes do not appear, restart app completely (close all Electron windows and run `npm run dev` again).
- If build fails after dependency updates, remove `node_modules` and reinstall:

```bash
rimraf node_modules package-lock.json
npm install
```
